# Guía de Economía de Experiencia para Profesores

Como profesor, el balance de XP es fundamental para mantener el compromiso sin trivializar el progreso. Aquí tienes las pautas estándar para asignar recompensas en **Aula-IT**.

## Rangos Recomendados

| Tipo de Actividad | XP Recomendada | Justificación |
| :--- | :--- | :--- |
| **Teoría / Lectura** | 10 - 50 XP | Recompensa el consumo de contenido base. |
| **Ejercicios Prácticos** | 50 - 150 XP | Valor medio para práctica recurrente. |
| **Retos / Entregables** | 200 - 500 XP | Esfuerzo significativo, requiere revisión. |
| **Hitos de Módulo** | 500+ XP | Proyectos finales o hitos críticos de carrera. |

## El Sistema de Calibración

En el editor de pasos, verás un indicador visual junto al campo de XP:
- **Azul Sólido**: Rango normal para la mayoría de actividades simples.
- **Ámbar / Brillo**: Indica un hito de alto valor (>500 XP). Úsalo con moderación para mantener el valor de la XP.

## Consejos de Diseño
1. **Modularidad**: Divide retos grandes en varios pasos pequeños (ej: Planificación -> Código -> Test) para dar feedback constante.
2. **Hitos Cooperativos**: Los hitos de clase (Milestones) suman la XP de todos. Un reto de 500 XP acerca a toda la clase a su pizza party o recompensa colectiva.
3. **Sentido de Escala**: Evita dar 10,000 XP por algo sencillo. Romperá la escala de niveles y el ranking de maestros de módulo.
